## Getting Started

### Dependencies

* A modern web browser such as Google Chrome, Microsoft Edge, Firefox, or Safari.
* No additional libraries or frameworks are required.
* An internet connection is recommended because the website loads Google Fonts.

### Installing

* Clone the repository:

```bash
git clone https://github.com/Tareq-Khalil/Builder-Info.git
```

* Navigate to the project folder:

```bash
cd Builder-Info
```

* No additional installation or configuration is required.

### Executing program

* Open the project folder.
* Open `index.html` in your preferred web browser.

Alternatively, you can use a local development server. For example, with VS Code and the Live Server extension:

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.
5. The website will open in your default browser.

## Help

If the website does not display correctly:

* Make sure `index.html` and `style.css` are in the correct locations.
* Make sure the stylesheet is linked correctly in `index.html`.
* Check your internet connection if the Google Fonts are not loading.
* If using Live Server, make sure the extension is installed and enabled.

For basic browser debugging, open the browser's developer tools with:

```text
F12
```
